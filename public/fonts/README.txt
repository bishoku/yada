YADA local font assets

Source: Fontsource npm packages, version 5.3.0.
https://fontsource.org/docs/getting-started/install

- `outfit`: Fontsource 5.3.0; original license in `outfit-LICENSE.txt`.
- `plus-jakarta-sans`: Fontsource 5.3.0; original license in `plus-jakarta-sans-LICENSE.txt`.
- `caveat`: Fontsource 5.3.0; original license in `caveat-LICENSE.txt`.
- `kalam`: Fontsource 5.3.0; original license in `kalam-LICENSE.txt`.

Only Latin/Latin Extended WOFF2 subsets are included for Turkish and English. Font data is unchanged.
UI families: Outfit, Plus Jakarta Sans (normal and italic).
Drawing families: Caveat, Kalam 400/700; sketch.css is requested on use.
